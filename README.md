# UniMate AI 🎓🤖

**AI-Powered University Management & Student Assistant**

UniMate AI is an AI-powered university management and student assistant designed to help students with their academic and career needs through one centralized platform.

It combines university management features with AI-powered assistance to provide students with personalized guidance, academic support, career planning, and learning resources.

## 🚀 Key Features

* 🤖 AI-powered student assistant
* 💬 AI Chat
* 🎤 Viva Coach
* 📚 Course Map
* ⏰ Deadline assistance
* 📄 Document assistance
* 💼 Career guidance
* 🧑‍💻 Internship guidance
* 🗺️ Personalized learning roadmaps
* 🌱 Student learning journey
* 💾 Conversation history
* 🎓 Academic record management
* 📊 Student-focused university dashboard

## 🛠️ Technology Stack

### Frontend

* HTML5

### Backend

* C#

### AI

## 🔐 Security

API keys and sensitive configuration are **not included in this repository**.

Groq API credentials should be configured locally using .NET User Secrets or environment variables.

## 🎯 Purpose

UniMate AI aims to provide students with a single intelligent platform where they can access academic assistance, AI guidance, career planning, internship support, and personalized learning resources.
